# Changelog

Notable project changes are recorded here. The format follows the principles of
Keep a Changelog, and releases will use semantic versioning once distribution
begins.

## Unreleased

### Added

- Initial project brief.
- Frontend architecture and approved technology direction.
- Tailwind-based design-system reference and MUI integration policy.
- Testing and large-graph performance strategies.
- Product requirements, UX flows, data contracts, accessibility, security, and
  error-handling specifications.
- Developer, deployment, observability, and architecture-decision documentation.
- Clean Code and SOLID engineering policy for implementation and future Cursor
  rules.
- React 19, TypeScript 6, and Vite 8 application scaffold.
- Tailwind CSS 4 design tokens and customized Material UI 9 theme.
- Validated Zod fixtures, normalized Zustand stores, and Cytoscape graph shell.
- Vitest, React Testing Library, Cypress, MSW, ESLint, and Prettier configuration.
- Complete frontend MVP workflows: graph exploration, connected-node
  highlighting, search/focus, status/type filters, layout switching, live
  deployment updates, connection creation/removal, and decommission impact.
- Responsive device details, accessible device table, dialogs, notifications,
  empty states, and locally hosted Instrument Sans typography.
- Incremental Cytoscape synchronization and a lazy-loaded graph bundle.
- Refined Untitled UI/shadcn-inspired dashboard hierarchy, simplified page
  header, and customized non-native MUI select menus across filters and forms.
