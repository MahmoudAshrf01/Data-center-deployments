DOCUMENT MAINTENANCE RULES

- A feature is not complete when its behavior contradicts these documents.
- Update requirements and contracts in the same change as affected code.
- Add or supersede an ADR when changing an architectural decision.
- Do not rewrite an accepted ADR to hide history.
- Mark unknown operational details explicitly rather than inventing values.
- Review links and status labels before a release.
